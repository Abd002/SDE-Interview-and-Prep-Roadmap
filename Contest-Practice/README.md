# Contest Practice PDFs

20 past contests to print and practise with: **7 Codeforces Div. 4**, **3 Codeforces Div. 3** and **10 AtCoder Beginner Contests** (151 problems).

- **One PDF per contest, printed from the site itself.** Codeforces contests are the site's own all-problems page (`codeforces.com/contest/<id>/problems`), so they look the same as saving it as PDF from the browser. AtCoder contests are AtCoder's own all-tasks print page (`atcoder.jp/contests/<abc>/tasks_print`). AtCoder's print style starts every task on a new page, so those files are longer.
- **The last page is the hints** for every problem in that contest.
- **[All-Contests.pdf](All-Contests.pdf)** is the 20 contest PDFs joined in order, each still followed by its own hints page.

## How the contests were chosen

- These are the most recent finished contests of each type with **no submission at all** from Codeforces handles **Abd002** and **_Khalifa**, or from AtCoder user **Abd002**. Wrong answers count too, so every problem should be unseen.
- Codeforces Round 1090 (Div. 4) was skipped because _Khalifa submitted there.
- ABC 477, 475 and 474 were skipped because they don't have complete official English editorials yet.

## Where the hints come from

Every hint comes from the contest's **official editorial**. None are made up.

- **Official hints:** if the editorial has "Hint" sections, all of them are copied word for word, in order.
- **Editorial first line:** otherwise the hint is only the **first sentence** of the official editorial. All AtCoder hints are this kind, because AtCoder editorials don't have separate hints.
