**9**   **Concurrent and Distributed Systems (SMH)**

&emsp;(a) Many distributed systems make use of replication.

&emsp;&emsp;&emsp;(i)   Give two advantages and one disadvantage of using replication.   \[3 marks\]

&emsp;&emsp;&emsp;(ii) Distinguish weak consistency and strong consistency. What is the primary<br>
&emsp;&emsp;&emsp;&emsp;&emsp;disadvantage of using the latter?   \[3 marks\]

&emsp;&emsp;&emsp;(iii) Describe how to commit a transaction in a distributed transaction<br>
&emsp;&emsp;&emsp;&emsp;&emsp;processing system in which objects are replicated on different servers.<br>
&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;\[4 marks\]

&emsp;(b)   Group communication can be achieved via ordered multicast. Describe how you<br>
&emsp;&emsp;&emsp;would build an ordered multicast system which preserves causal ordering.<br>
&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;\[6 marks\]

&emsp;(c)   You are part of a team tasked with building a distributed filing system. One of<br>
&emsp;&emsp;&emsp;the requirements is that it must be possible to revoke access rights to a file within<br>
&emsp;&emsp;&emsp;T milliseconds (T ≥0). Describe how you could achieve this, commenting on<br>
&emsp;&emsp;&emsp;how the value of T would influence your decision.   \[4 marks\]
