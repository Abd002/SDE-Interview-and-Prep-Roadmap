## Legends (used in every file)

| Legend | Values |
|---|---|
| **Priority** | **P1** = best fit, apply first · **P2** = good fit · **P3** = backup or opportunistic |
| **Status** | Not started → Preparing → Applied → Interview → Offer / Rejected / Withdrawn |
| **Visa sponsorship** | ✅ **Verified**: the company's own statement, or official data (UK sponsor register, Dutch IND register, US DOL LCA data) · 🟡 **Likely**: named by third-party lists only · ❔ **Unconfirmed** · ❌ **No** |
| **Programme status** | 🟢 Open · 🟡 Upcoming · 🔴 Closed or not eligible yet · ⚪ To confirm / partial · ⚫ Discontinued |
| **Verified on** | `2026-09-29 · S` = checked on that date via web-search results for the linked page; the page itself was not opened · `2026-10-01 · O` = the official or primary page (sponsor register, live job board, careers page, LinkedIn job posting) **was opened** on that date |

## How to keep it current

- **Every January:** update the visa thresholds in [06](06-Salaries-and-Visas.md) (Germany, Netherlands, UK, Ireland, Sweden all change yearly).
- **Every August–September:** refresh the deadlines in [05](05-Masters-and-Scholarships.md) for the next intake.
- **Before each application:** open the careers page, and check the official sponsor register ([UK](https://www.gov.uk/government/publications/register-of-licensed-sponsors-workers), [NL](https://ind.nl/en/public-register-recognised-sponsors)). Then change 🟡 to ✅ in the table if the company is listed.
- **After each application:** update [08](08-Application-Tracker.md).
