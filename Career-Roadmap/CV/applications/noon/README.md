1. **The assessment is almost certainly algorithmic.** You're strong here; do a few timed LeetCode mediums in Python to be fluent in Python syntax, not only C++.
2. **Technical interviews:** data structures and algorithms, plus basic backend topics: REST design, SQL (joins, indexes, transactions), and how you'd model data for an e-commerce cart or orders. Your notes in [Progress-Summary §3.1–3.5](../../../Progress-Summary.md#3-what-i-can-explain-now) cover SQL and storage.
3. **Behavioural interviews (two):** prepare 4–5 STAR stories: the libcups crash fix, choosing Zephyr at EKSON, the 40% asyncio improvement, mentoring 20+ people at ICPC, managing the IEEE budget.
