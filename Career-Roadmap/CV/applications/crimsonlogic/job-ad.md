# Job ad: CrimsonLogic, Junior System Engineer, Muscat (Oman)

Saved on 3 Nov 2026 from https://www.linkedin.com/jobs/view/4475189924 (posted 7 Oct 2026, Entry level, Contract), in case the posting closes.

Job Summary
We are looking for a motivated Junior System Engineer to join our Infrastructure team. This position is suitable for fresh graduates and candidates with up to 2 years of experience who have a basic understanding of Linux, networking, web servers, and system administration. The selected candidate will assist in managing IT infrastructure, supporting applications, troubleshooting technical issues, and ensuring the availability of systems and services.
Key Responsibilities
- Monitor and maintain Linux and Windows servers.
- Assist in application deployment and server administration activities.
- Monitor system health, including CPU, memory, disk space, and network utilization.
- Troubleshoot server, application, and network-related issues.
- Review application and system logs for issue analysis and resolution.
- Support and maintain Apache Web Server and Apache Tomcat environments.
- Assist in deploying and configuring web applications on Apache and Tomcat servers.
- Support user account management and access control activities.
- Assist with system patching, backup, and maintenance activities.
- Document configurations, procedures, and troubleshooting steps.
- Follow IT security policies and operational best practices.
- Coordinate with application, database, and network teams to resolve issues.

Required Qualifications
- Bachelor's Degree in Computer Science, Information Technology, Computer Engineering, Network Engineering, or a related field.
- 0–2 years of experience in IT Infrastructure, System Administration, or Technical Support.
- Fresh graduates are encouraged to apply.
- Basic knowledge of Linux administration (RHEL, CentOS, Ubuntu, etc.).
- Basic understanding of networking concepts such as TCP/IP, DNS, DHCP, VLANs, routing, and subnetting.
- Basic knowledge of Apache Web Server and Apache Tomcat.
- Basic understanding of SQL and database concepts.
- Good analytical and problem-solving skills.
- Good verbal and written communication skills.
- Ability to work independently and as part of a team.

Preferred Skills
- CCNA certification or equivalent networking knowledge.
- RHCSA certification or ongoing RHCSA training.
- Knowledge of cloud platforms such as AWS and/or Azure
- Familiarity with Apache HTTP Server and Tomcat configuration.
- Basic scripting knowledge (Bash, Shell Scripting, or Python).
- Understanding of cloud services such as Virtual Machines, Storage, Networking, Load Balancers, and Security Groups.
