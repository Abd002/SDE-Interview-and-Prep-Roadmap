# DXC Technology: Junior Backend Java Microservices Developer, Fresh Graduates: job ad

Saved 26 Nov 2026 from [LinkedIn](https://www.linkedin.com/jobs/view/4492017507). Riyadh, Saudi Arabia.

Junior Backend Java Microservices Developer – Fresh Graduates
Location: KSA
We are seeking a motivated Junior Backend Java Microservices Developer to help build and scale the core server-side systems powering our applications. You will work within an Agile engineering team to develop resilient Java microservices, design efficient database interactions, and build high-performance APIs. This role offers strong mentorship and hands-on exposure to cloud-native distributed architectures.
Key Responsibilities
- Backend Service Development. Design, code, test, and maintain modular backend microservices using Java and Spring Boot.
- API Engineering. Develop well-documented, secure RESTful APIs (using OpenAPI/Swagger) to support web, mobile, and third-party integrations.
- Data Persistence & Optimization. Build data access layers using Spring Data JPA/Hibernate, write optimized SQL queries, and assist with database schema migrations (e.g., Flyway or Liquibase).
- Service-to-Service Communication. Implement synchronous (REST/Feign) and asynchronous (event-driven messaging) communication patterns between microservices.
- Automated Testing. Write comprehensive unit, slice, and integration tests using JUnit 5, Mockito, and Testcontainers to maintain high code quality.
- Production Support & Observability. Monitor service health using structured logging and metrics, troubleshoot backend bugs, and participate in peer code reviews.
Required Qualifications & Skills
- Education. Bachelor’s degree in Computer Science, Software Engineering, or a related technical discipline (or equivalent practical project experience).
- Experience. 0–2 years of backend development experience through junior roles, internships, or substantial software projects.
- Java Ecosystem. Solid grasp of modern Java (Java 17+), OOP principles, Streams API, Collections, Exception Handling, and concurrency basics.
- Spring Boot & Microservices. Hands-on experience with Spring Boot, Spring Web, Spring Data JPA, and core microservices patterns (e.g., API Gateway, Circuit Breaker, centralized config).
- Databases. Strong understanding of relational databases (PostgreSQL, MySQL, or MS SQL) and ACID transaction principles.
- Engineering Tools. Proficiency with Git workflows, Maven or Gradle build tools, and API testing clients like Postman or cURL.
