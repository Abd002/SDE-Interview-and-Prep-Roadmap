## 3. How to apply

- Apply through the YC board ("Apply to role"); you need a free Work at a Startup profile. Upload the CV and fill the profile from your LinkedIn.
- The profile asks for a short intro. Keep it to 3–4 lines in your own words: what you build for fun (cosmic-printers, kernel-monitor, the CMU database projects), that you love Linux and Rust, and that you're in Egypt.
- **Before applying:** install PostgreSQL locally and run the CMU homework queries on it once, so you can honestly say you've used it. Pin cosmic-printers, GSOC-2026, kernel-monitor and db-systems-journey on GitHub; they will look.
