# Job ad: Junior Embedded Software Engineer, Secure IoT Firmware

> Saved on 18-19 Oct 2026 from <https://nxp.wd3.myworkdayjobs.com/careers/job/Gratkorn/Junior-Embedded-Software-Engineer---Secure-IoT-Firmware--m-f-d-_R-10066519> so the text is still here if the posting closes. Text as extracted from the page (layout lost).

Join our team working at the intersection of embedded security and connected IoT devices . As a Junior Embedded Software Engineer, you will contribute to firmware powering secure device provisioning, over-the-air updates, and trusted execution environments on Arm Cortex-M MCUs . This is an excellent opportunity for candidates early in their career who are eager to build expertise in embedded security and connected device lifecycle management. Your Responsibilities - Develop and test Provisioning Firmware that securely binds devices to specific OEMs at manufacturing sites (RTP provisioning). - Implement and validate a security framework for trusted execution on Arm Cortex-M MCUs, including core components and example applications. - Build and test secure key provisioning applications running on FreeRTOS and Zephyr RTOS. - Develop and maintain OTA Firmware Update flows for connected devices. - Manage distribution and release of embedded SW through multiple distribution portals. - Contribute to the architecture and design of secure device management solutions. - Collaborate with the backend team on microservices responsible for device abstraction. Your Profile - University degree in Software Engineering, Computer Science, Electrical Engineering, or a related field. - Strong C programming skills; experience with Assembler is a plus. - Solid understanding of 32-bit microcontroller architectures and embedded software design. - Exposure to embedded software verification methodologies (unit testing, integration testing). - Curious, fast learner — comfortable picking up new tools, standards, and protocols quickly. Nice to Have: - Knowledge of embedded security concepts: cryptographic algorithms, Arm TrustZone, secure boot. - Scripting experience in Python or Groovy for build/test automation. - Object-oriented programming background in Java (relevant for backend collaboration). - Experience with RTOS environments (FreeRTOS, Zephyr). What Makes This Role Unique - Work on security-critical firmware that ships in millions of IoT devices worldwide. - Gain hands-on experience with security frameworks, TrustZone, and NXP's embedded security ecosystem. - Bridge embedded firmware and backend services — a rare full-stack IoT security perspective. Please note: The successful candidate may/will be responsible for security related tasks. The assignment may/will be in scope of security certifications, therefore a conscious and reliable way of working is necessary.
