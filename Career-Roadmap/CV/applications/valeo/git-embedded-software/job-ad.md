## Job description
Join us for six intense months in the R&D Team to gain the essential professional skills and global exposure needed to drive your success.

## Key responsibilities
- Develop and maintain software code based on defined component requirements and component design.
- Apply standard software guidelines, including MISRA-C rules and Valeo naming rules.
- Configure the different software components according to the specified requirements.
- Deliver and integrate the software component in the overall software according to the defined high-level design.
- Develop component test plans and test cases to verify the correct functionality against the requirements.
- Verify the software component functionalities on a defined HW target/platform.
- Verify the software component performance indicators.
- Execute static analysis tools and analyze the results.
- Follow defined project processes and ensure process conformance.
- Report work progress through daily and weekly project meetings.
- Contribute to continuous improvement by submitting improvement proposals; raise flags proactively for any issue.
- Plan and execute test plans; analyze results and confirm the software respects the requirement documents.
- Report findings (software bugs) in the configuration management tool.

## Required skills and qualifications
- Recent graduate of 2026 or 2025.
- Bachelor's degree in Communication, Mechatronics, Electronics, Computer Engineering or Computer Science.
- Excellent English and Arabic, written and spoken. French is a strong plus.
- Works well in a team.
